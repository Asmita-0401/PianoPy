PianoPy is a simple virtual piano app built using Python. It allows users to play musical notes using the keyboard and is a fun way to explore sound, input handling, and GUI creation in Python.

---

## ✨ Features

- 🎵 Play piano sounds using keyboard keys
- 🖼️ Simple graphical interface (optional with `tkinter` or `pygame`)
- 🔊 Real-time audio playback using Python libraries
- 🧠 A beginner-friendly project for learning sound programming and event handling
